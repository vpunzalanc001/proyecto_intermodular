# Red Segura y Servidores para Empresa de Soporte Técnico

## Información del Proyecto
* **Autor:** Vanessa Punzalan
* **Estudios:** 2º ASIR (Administración de Sistemas Informáticos en Red)
* **Centro:** IES Augustóbriga (Navalmoral de la Mata)

## Descripción
Diseño de la infraestructura informática para **TechSupport**, una empresa con 5 departamentos (TI, Operaciones, RRHH, Administración y Finanzas). El sistema incluye servidores virtuales, una red dividida para proteger los datos y una base de datos centralizada para gestionar tickets de clientes.

## Objetivos Principales
* **Dividir la red:** Crear 5 redes separadas (VLANs) para aislar los departamentos.
* **Servidores:** Instalar servidores virtuales con Linux para la base de datos de tickets.
* **Seguridad:** Configurar un firewall (pfSense) y copias de seguridad automáticas.
* **Servicios:** Configurar servicios básicos de red como Internet, DNS y DHCP.

## Tecnologías Utilizadas
* **Virtualización:** VirtualBox / VMware
* **Sistemas Operativos:** Ubuntu Server y pfSense
* **Base de Datos:** MySQL / PostgreSQL
* **Automatización:** Scripts para copias de seguridad diarias

## Asignaturas Aplicadas
* Gestión de Bases de Datos
* Planificación y Administración de Redes
* Administración de Sistemas Operativos en Red
* Seguridad y Alta Disponibilidad
* Implantación de Aplicaciones Web y Lenguajes de Marcas
